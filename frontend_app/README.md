# Proyecto Frontend Portal

## Ejecutar

```powershell
cd "t:\U3 backend\frontend_app"
..\..\.venv\Scripts\Activate.ps1
python manage.py runserver 0.0.0.0:8000
```

## Login

Este proyecto consume la API del proyecto API en http://localhost:8050/api

## Restricciones

- Sin formularios automáticos.
- Sin admin de Django.
- Sin base de datos local.
